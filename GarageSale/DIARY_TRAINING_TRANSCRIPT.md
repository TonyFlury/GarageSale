# Garage Sale Diary training transcript

The opening diagrams explain templates, dependencies, and task states before the screen demonstrations.

## 00:00:00 — Your tasks, in one place

Welcome to the Garage Sale Diary. A diary is the task list for an event. A task is a piece of work. Its due date is when that work should be finished. Its owner is the responsible person or group. Alex is a Diary User who works on assigned tasks. Orange highlights show the controls we use.

## 00:00:23 — Templates and event milestones

A template is a reusable set of tasks known in advance. The left side shows two example tasks and their date rules. A milestone is a key event date, such as bookings opening or the event day. When an event diary is created, its milestone dates determine the task due dates. Here, advertising opens on the third of November. Preparation is due seven days earlier, on the twenty-seventh of October. Another event uses the same template with its own dates and separate progress. The details of template creation and management are covered elsewhere. We will use the tasks already created for this event.

## 00:01:11 — Dependencies, readiness, and blocking

Some tasks must finish before other tasks. These links are called dependencies. Tasks generated from a template can be linked this way. The earlier required task is called a predecessor. In the top row, Prepare advertising bookings is unfinished. Open advertising bookings is therefore Blocked. Blocked means an earlier required task has not finished. In the bottom row, the preparation is completed. The next task becomes Ready, which means it has no unfinished predecessors. It is not completed automatically, and its due date does not move.

## 00:01:55 — Late and Blocked are separate labels

Late and Blocked describe different things. Late means a task is unfinished and its due date is today or earlier. Blocked means an earlier required task is unfinished. Being blocked does not change the due date. Look at the top row. With no unfinished predecessors, both tasks are Ready. The task due today or earlier also shows Late. Now look at the bottom row. Both tasks are Blocked. Only the one due today or earlier also shows Late. The interface uses these separate labels. A completed task is neither late nor blocked.

## 00:02:38 — Filter the list

We are back on My Diary. The default list shows ready work and hides blocked tasks. Select show blocked also. Whole-team tasks are shared by the entire Diary team. Select include whole-team tasks. Now choose Apply filters. The list now includes the selected work. Filters change what you see; they do not complete tasks or remove dependencies.

## 00:03:14 — Use a specific status

Task status offers All open tasks, Late only, Ready and not late, and Blocked and not late. Choose Blocked and not late. Choose Apply filters. This selection shows blocked tasks whose due dates are still in the future. Choose the Late status link. Late includes unfinished tasks due today or earlier, whether they are Ready or Blocked. A task showing both labels is counted here. Choose Clear filters to restore the default list.

## 00:03:55 — Add your own task

Choose Add task to create a personal reminder. Ordinary users create tasks for themselves. They cannot assign another owner or add their task to the shared template. Personal additions are private from other ordinary users, but Diary Managers can inspect them. A private task cannot be used as a dependency.

## 00:04:20 — Choose the name and date rule

Enter the task name, Call the printing company. Enter a short description of the work. A date rule tells the diary how to calculate a task due date. We will use an exact date for this reminder. Choose One-time date. Enter the date in the One-time date field. A milestone rule uses an event milestone. An annual rule selects a month and day; it does not create a repeating task. Complete only the fields for the selected rule. This personal-task form has no dependency editor. Choose Add task to save the reminder.

## 00:05:08 — Inspect your saved task

Return to the My Diary page using the sidebar. Keep the default filters. Find the task named “Call the printing company” in this ready-task list. Choose its View and update task button. Its source is Diary addition, meaning it was created directly in this diary. It belongs to Alex and has no open predecessors. It is Ready. This task does not change the template or other event diaries.

## 00:05:44 — Change a personal due date

You can change the due date of your own open personal addition. Enter the revised due date. Choose Save due date. This changes this diary only. Ordinary users cannot change copied template-task dates. Completed tasks cannot have their due dates changed.

## 00:06:09 — Progress notes on template and private tasks

Progress notes apply to both template-generated tasks and private tasks. Assigned users and managers can add them. We will first use Alex’s private reminder, then show a note on a shared template task. The saved history retains earlier notes and actions. Enter a note about the conversation with the printer. Choose Add note. The saved note shows its author and time. New notes do not replace older notes. Assigned users and managers can add notes, including after completion.

## 00:06:49 — Complete finished work

When the work is finished, choose Complete. The completion history records who completed the task, when, and its due date at completion. It leaves the personal open-task list. A note alone does not complete work. You can still add a follow-up note to this completed record.

## 00:07:12 — Understand an open predecessor

Return to the My Diary page using the sidebar. Select show blocked also. Choose Apply filters to show that work in the list. Find the task named “Open advertising bookings”. Choose its View and update task button. This task shows both Blocked and Late. It is Blocked because Prepare advertising bookings is unfinished. It is Late because its own due date has arrived. Open predecessors lists the earlier work that must finish first. These are separate checks.

## 00:07:56 — Blocked work cannot complete normally

Choose Complete while that predecessor remains unfinished. The diary rejects the action, and nothing is completed. Resolve the earlier work first. Diary Users cannot bypass this dependency. We will show the manager alternative later.

## 00:08:17 — Record progress on shared work

Return to the My Diary page using the sidebar. Select show blocked also. Choose Apply filters to show that work in the list. Find the task named “Prepare advertising bookings”. Choose its View and update task button. This task was generated from the template. Progress notes work here too, just as on the private reminder. Alex belongs to its assigned group and can add a note. It shows Ready and Late: its predecessors are finished, but its due date has arrived. Enter a note describing the preparation checks. Choose Add note. Alex cannot change the date of this copied template task.

## 00:09:15 — Complete the predecessor

On the task named Prepare advertising bookings, choose Complete. This completes that task only. The diary checks the saved dependency links again. It does not automatically complete Open advertising bookings; it makes that next task available.

## 00:09:36 — The next task is now ready

Return to the My Diary page using the sidebar. Select show blocked also. Choose Apply filters to show that work in the list. Find the task named “Open advertising bookings”. Choose its View and update task button. It is now Ready, with no open predecessors. Its due date has not moved, so it still shows Late. Being ready to work on does not mean being on time. After performing the work, choose Complete. The next task is now recorded as completed.

## 00:10:24 — Review the full event diary

We now switch to Morgan, a Diary Manager. The sidebar provides Manager Diary and Templates. Choose Manager Diary. This is the full permitted event diary, including personal additions. Managers can inspect tasks, add notes, create assigned work, and change permitted dates. A template task with no eligible owner is called orphaned. Managers can recover those assignments.

## 00:10:56 — Manager filters

Manager Diary offers include completed tasks, exclude blocked tasks, and exclude non-late tasks. Selected filters are applied together. Select include completed tasks. Select exclude blocked tasks. Choose Apply filters. Completed records are included, while blocked work is hidden. Completed tasks are never marked Late or Blocked. Choose Clear filters.

## 00:11:33 — Find late tasks

Select exclude non-late tasks. Choose Apply filters. This focuses on unfinished tasks due today or earlier. Filtering does not complete work or remove dependencies. Choose Clear filters to review the full open-task list.

## 00:11:57 — Orphaned template tasks appear first

The task named Close advertising bookings appears first because it is orphaned. Its original owner, Jamie, became inactive after diary creation. Only template tasks qualify for this recovery. A manager can leave the task unresolved, but it remains unfinished and keeps dependent tasks blocked.

## 00:12:20 — Choose a replacement owner

Return to the Manager Diary page using the sidebar. Find the task named “Close advertising bookings”. Choose its View and update task button. Use the normal task editor to assign an eligible replacement. Person means an active eligible Diary User. An ownership group assigns work to its eligible members. Whole team makes the work shared. Choose Person as the new owner type. Choose Alex Green as the new person. Choose Assign owner. Alex is now the owner. Recovery applies to open orphaned template tasks; it is not unrestricted reassignment of every task.

## 00:13:15 — Recovery preserves the task

Recovery preserves the task identity, due date, and dependencies. It does not rewrite the source template or other event diaries. Review template ownership separately for future events. Enter a note explaining the ownership handover. Choose Add note.

## 00:13:38 — Change a template task due date

Managers can change an open copied template task date. A date override replaces its calculated date in this diary only. For Close advertising bookings, enter the revised due date. Choose Save due date. The original milestone rule remains recorded. The diary does not warn if an override causes a scheduling conflict. Check dates and dependencies yourself.

## 00:14:11 — Create a manager-assigned task

Return to the Manager Diary page using the sidebar. Choose Add task. Managers can assign a person, an authorized ownership group, or Whole team. Enter the task name, Confirm equipment collection. Choose One-time date. Enter the exact due date in the One-time date field. Choose Ownership group as the owner type. Choose ExecMember as the ownership group.

## 00:14:50 — Keep diary work separate from templates

The lower section offers Add to template for future diaries. That separate option requires a reusable date rule. We leave it off for this task. Choose Add task to save this diary addition only. Existing diary dependencies stay fixed. The new addition is not inserted into their dependency chain.

## 00:15:16 — Inspect the blocking chain first

Return to the Manager Diary page using the sidebar. Find the task named “Complete final event checks”. Choose its View and update task button. Open predecessors shows the unfinished advertising and sale-booking chain. Normal Complete requires that work to finish. A manager can instead use Close all to complete the selected task and its unfinished predecessors together. That is forced completion.

## 00:15:51 — Close all completes the open chain

Close all records completion of the whole unfinished chain. It does not just hide a warning or remove a dependency. Inspect the chain and use it only when that completion is intended. Choose Close all for this demonstration. The history records Morgan as the manager who used Close all.

## 00:16:15 — Review the completion history

Return to the Manager Diary page using the sidebar. Select include completed tasks. Choose Apply filters. The completed records show who acted and when. Run the Garage Sale is a separate later task. Completing its predecessor makes it Ready, but does not complete it.

## 00:16:43 — Audit a forced predecessor

Return to the Manager Diary page using the sidebar. Select include completed tasks. Choose Apply filters. Find the task named “Close advertising bookings”. Choose its View and update task button. Its history records forced completion for Complete final event checks. The earlier handover note remains. Review these records before taking another action. Reload the task if the diary reports that its saved state has changed.

## 00:17:25 — A practical daily routine

For everyday work, check the due date and the task labels separately. Late means unfinished and due today or earlier. Blocked means an earlier required task is unfinished. Use notes for progress and Complete for finished work. Managers review orphaned tasks and use Close all carefully. This concludes the walkthrough.
