# Sponsorship email template context

`SponsorSpreadsheetView._sponsor_template_contexts()` in `Sponsors/views.py` builds a separate context for each selected sponsor, shared by email delivery and the PDF ZIP download. Use `{{ variable_name }}` in the communication template's subject or HTML content. Named template attachments receive the same context when rendered as PDFs. Standalone PDFs include selected sponsors even when they have no email address.

Event and request values are generated by `CommunicationTemplate.default_context()` and applied automatically to all email and PDF templates, regardless of category. These defaults are `current_event`, `event`, `event_date`, `event_logo`, `year`, `current_date`, `supporting`, `supporting_icons`, and `base_url`. Explicit caller values take precedence. The event comes from a caller-provided `current_event` or `event`, then `request.current_event`; when the request has no event attribute, the latest activated event is used. Without a request or event, event text and icons are empty. The calling app still provides `from` and recipient-specific values.

## Variables available to template authors

| Variable | Value and defaults | Example |
| --- | --- | --- |
| `contributor_name` | Sponsor's contributor name. | `Acme Ltd` |
| `company_name` | Alias of `contributor_name`; contains the same text. | `Acme Ltd` |
| `contact_name` | Contact name, with surrounding whitespace removed. Defaults to `Sirs` when absent or blank. | `Alex Smith` |
| `attn` | `For Attn of :` followed immediately by the trimmed contact name. Empty string when no contact name is provided; does not use the `Sirs` fallback. | `For Attn of :Alex Smith` |
| `base_url` | Website root URL derived from the incoming request, including scheme, hostname, any port, and a trailing slash. Added by the shared CommunicationTemplate renderer for emails and PDFs; empty string without a request. | `https://example.com/` |
| `event_date` | Current event's date display text, as returned by `get_event_date_display()`. Empty string without an event. | Event's configured date display |
| `event_logo` | Full absolute URL of the current event's logo. Empty string without an event or logo. | `https://example.com/media/event-logo.svg` |
| `year` | Four-digit year of the current event. Empty string without an event. | `2027` |
| `current_date` | Local date when sending, as a date value. Use Django's date filter to control its presentation. | `{{ current_date\|date:"d/m/Y" }}` |
| `supporting` | Organisation names ordered by their display index then primary key. Names are separated by comma and space, with ` and ` before the last name. One name is displayed alone; two names use only ` and `. Empty string without organisations or an event. | `Local Hospice, Food Bank and Youth Club` |
| `supporting_icons` | Ready-to-insert HTML containing the supported organisations' `<img>` tags in the same order as `supporting`. Organisations without logos are omitted. Empty string when there are no icons. | `{{ supporting_icons }}` |
| `previously_confirmed` | Boolean: whether this sponsor has a `Confirmed` Contributor Event record for any event dated before the current event. Without a current event, the cutoff is today. | `True` or `False` |
| `donation` | Total valid cash contributions for this sponsor and current event, formatted in pounds. Only present for sponsors confirmed for the current event who have a valid cash contribution. Whole amounts omit pence; fractional amounts use two decimal places. | `£50` or `£25.50` |
| `current_event` | Current event model object, or `None` without an event. Prefer the flat variables above for text replacement. | Event object |
| `event` | Alias of `current_event`; contains the same object. | Event object |

The current event comes from `request.current_event`, falling back to `get_current_contribution_event()`. A past event cannot have confirmed sponsors. A sponsor is confirmed when their current-event status is `Confirmed` under the spreadsheet's confirmation rule.

The reusable icon layout is `GarageSale/templates/email/icon_set.html`. It receives an ordered `icons` list containing `url` and `name`. Its default image height is 64 pixels, and image attributes are escaped. The resulting HTML is marked safe for direct insertion with `{{ supporting_icons }}`.

`donation` is absent rather than an empty string when it does not apply. Django renders a missing variable as empty text by default. Invalid, negative, or non-finite cash values are skipped and logged; non-cash contributions are excluded.

## Example HTML content

```django
<p>{{ attn }}</p>
<p>Dear {{ contact_name }},</p>
<p>Please support our {{ year }} event on {{ event_date }}.</p>
<p>We are supporting {{ supporting }}.</p>
{{ supporting_icons }}
{% if donation %}<p>Thank you for your donation of {{ donation }}.</p>{% endif %}
{% if previously_confirmed %}<p>Thank you for your previous support.</p>{% endif %}
```

## Delivery and PDF-only values

| Variable | Purpose and availability |
| --- | --- |
| `email` | One-element list containing the sponsor's email address. Consumed and removed by `CommunicationTemplate.render_template_as_email()` before rendering the subject or body. Not available for text replacement. Sponsors without an email address are skipped. |
| `from` | Sender address from `settings.APPS_SETTINGS["Sponsors"]["EmailFrom"]`. Also consumed and removed before rendering. |
| `host` | Request hostname, added by `CommunicationTemplate.get_header_text()` when rendering a named attachment as a PDF. Not supplied to the email subject or body. |
| `scheme` | Request URL scheme (`http` or `https`), added during PDF rendering. |
| `summary` | Summary of the attachment template being rendered, added during PDF rendering. |

There are no `sponsor`, `contributor`, or `contributions` variables. The Sponsor template category is selected using `settings.APPS_SETTINGS["Sponsors"]["EmailTemplateCategory"]`; it is configuration, not a context variable.
